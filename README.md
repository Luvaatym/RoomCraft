# RoomCraft

RoomCraft — веб-приложение для интерактивного планирования помещений в 2D.

Пользователь сможет задать размеры комнаты, разместить мебель на плане помещения и проверить расстановку на возможные проблемы: пересечение объектов, выход мебели за границы комнаты и слишком узкие проходы.

## Тип проекта

Web-приложение.

## Основная идея

Главная особенность RoomCraft — автоматическая проверка практической удобности расстановки мебели.

## Планируемые технологии

- Frontend: React, JavaScript, HTML, CSS
- 2D-редактор: Konva.js / react-konva
- Backend: C#, ASP.NET Core
- База данных: PostgreSQL
- Работа с базой данных: Entity Framework Core
